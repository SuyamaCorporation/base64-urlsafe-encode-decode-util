# Base64/Base64URL安全エンコード＆デコードツール

テキスト文字列またはHEX文字列を入力し、Base64標準・Base64URL（RFC 4648 §5）・Base32の3形式で同時エンコード出力します。
パディング(=)の有無を切り替え可能で、各フォーマットのバイト数・文字数・エンコード後長さも表示します。
デコードモードに切り替えると、Base64/Base64URL/Base32の文字列を元のテキスト・HEXバイト列に復元できます。
各出力横のコピーボタンでワンクリックコピーに対応しています。

## 使い方

入力エリアにテキストまたはHEX文字列を貼り付けると即座に変換結果が表示されます。「デコードモード」チェックで逆変換も可能です。
